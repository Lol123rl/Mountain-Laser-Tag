# Mountain Laser Tag

Mountain Laser Tag is a 3D laser-tag game created in Godot 4.

The game includes Blue Team vs. Red Team combat, multiple game modes, AI-controlled players, a minimap, upgrades, helicopters, achievements, and a final boss.

## Source Recovery

The original local Godot project was lost after an earlier attempt to move the large project through GitHub.

This repository contains genuine surviving source code recovered from the project's development history. Hackatime contains the original development activity and time records.

Some original assets, scenes, terrain, models, and audio files could not be recovered.

The `project.godot` and `main.tscn` files in this repository were created as a small reconstruction so the recovered source can be organized as a Godot project.

## Main Source Files

- `scripts/BattleManager.gd` — main game systems, teams, game modes, AI, UI, economy, objectives, achievements, helicopters, and final boss
- `scripts/Player.gd` — player movement, shooting, health, stamina, ammunition, and helicopter interaction
- `recovered_history/` — earlier surviving versions of the project's source code

## Engine

Godot 4 / GDScript

## Development History

Development time was tracked with Hackatime. The Hackatime activity predates this reconstructed GitHub repository because the original local project files were lost.
